# PCMonitor Pro · 手机 APP 安装与使用说明

一个真正的安卓 APP（APK），手机装上就能实时查看电脑的运行状态。
项目总览与电脑端部署见 [主 README](../pc-monitor/README.md)。电脑端服务需以管理员身份运行。

---

## 版本号规则

版本号采用 `主.次.修订`（语义化版本）三段式：

| 段 | 含义 | 何时 +1 |
|----|------|---------|
| 主版本号 | 大改版（界面重构、架构调整） | 大改版 |
| 次版本号 | 加功能（新增数据项、新页面、新交互） | 每次加功能 |
| 修订号 | 修 bug | 只修 bug 不动功能 |

- APK 文件名形如 `电脑监测_v2.1.0.apk`。
- 每次发新 APK，"关于"页同步更新版本号，并附一行更新说明（本次改了啥）。
- 当前版本：**2.1.0**（versionCode 2）。

## 一、你需要准备的两样东西

| 东西 | 位置 | 说明 |
|------|------|------|
| ① 手机 APP | `pc-monitor-app/电脑监测.apk` | 安卓手机安装文件 |
| ② 电脑采集程序 | `pc-monitor/agent.py` | 在电脑上跑起来即可 |

手机和电脑必须连在**同一个 WiFi / 路由器**下。

---

## 二、电脑端：跑起采集程序（先做这步）

1. 打开 `pc-monitor` 文件夹
2. 双击 **`start.bat`**（首次会自动装依赖，等十几秒）
3. 窗口里会打印一行手机访问地址，例如：

   ```
   手机访问: http://192.168.1.8:8888
   ```

   记下这个 **IP**（`192.168.1.8`）和 **端口**（`8888`），后面要填进手机 APP。

> 想开机自动启动：右键 `install_autostart.bat` → 以管理员身份运行，一次搞定。

---

## 三、手机端：安装 APP 并连接

1. 把 `电脑监测.apk` 传到手机上（微信/QQ 文件传输、数据线、网盘都行）
2. 在手机上点击该文件安装（首次需允许"安装未知来源应用"）
3. 打开 APP，底部点 **「设置」**
4. 填上电脑的 IP 和端口（**只填数字和点，不要带 http:// 或冒号端口**）：
   - **IP 地址框**：只填 `192.168.1.5`（你在电脑窗口看到的 IP）
   - **端口框**：只填 `8888`
5. 点「保存并连接」，回到首页顶部圆点变**绿色**即连接成功

> **举例**：电脑上 `start.bat` 窗口显示 `手机浏览器访问: http://192.168.1.5:8888`，
> 那 APP 里就填：IP = `192.168.1.5`、端口 = `8888`。
> 如果你把 `192.168.1.5:8888` 或 `http://192.168.1.5` 整个粘进 IP 框，APP 也会自动帮你清洗成正确的格式。

> **连接失败会显示具体原因**（顶部红点旁小字）：超时 / 防火墙拦截 / 明文被禁 / HTTP 错误码，照着提示排查即可。服务端每次收到请求也会在黑窗口打印一行日志，可确认 APP 是否真的连过来了。

## 四、APP 功能一览

底部 4 个标签：

- **性能**：CPU（总/每核心使用率、主频、温度、功耗）+ GPU（使用率、显存、温度、功耗、频率、风扇）
- **存储**：内存（已用/总量/使用率）+ 固态硬盘（读写速度、剩余空间、温度、寿命）
- **状态**：网络（上下行/延迟）、温度（CPU/GPU/硬盘/主板）、电池（电量/充电/健康/续航）、进程（分组显示）
- **设置**：服务器 IP 端口、刷新间隔、告警阈值、深色/浅色主题

**进程页**：顶部总览（进程数/线程数/开机时长），按「无响应 / 运行中 / 已挂起」分组，可展开收起、按 CPU 或内存排序，无响应进程标红置顶。

**能测到才显示**：读不到的数据（如 CPU 温度、硬盘温度、整机功耗）会自动隐藏该项，不会出现 N/A 占位。

## 五、常见问题

**Q：手机连不上，圆点一直红？**
- 确认手机和电脑在同一 WiFi
- 确认电脑上的黑色窗口还开着（采集程序在运行）
- 99% 是电脑防火墙拦截，在电脑上**管理员**运行一次：
  ```
  netsh advfirewall firewall add rule name="PCMonitor" dir=in action=allow protocol=TCP localport=8888
  ```

**Q：CPU 温度 / 硬盘温度 / 风扇转速不显示？**
- Windows 本身不提供这些数据，需要装免费的 **LibreHardwareMonitor**（运行它即可，agent.py 会自动读取）。详见 `pc-monitor/README.md`。

**Q：电脑 IP 变了连不上？**
- 电脑重启后 IP 可能变化，重新看 `start.bat` 窗口打印的地址，在 APP 设置里更新即可。
